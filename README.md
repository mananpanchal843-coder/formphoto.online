# FormPhoto

Free browser-based photo & signature tools for Indian exams and forms.

## Stack

- React + Vite
- React Router
- Deploy: Netlify

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output: `dist/`

## Netlify

- Build command: `npm run build`
- Publish directory: `dist`
- Node: 20

`netlify.toml` is already configured.
